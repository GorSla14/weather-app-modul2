# Weather App – Modul 2

A weather application built with HTML, CSS, JavaScript, jQuery and OpenWeather API.

## Setup

1. Create a file named `config.js` in the project folder.
2. Copy the contents of `config.example.js` into it.
3. Replace `YOUR_OPENWEATHER_API_KEY` with a valid OpenWeather API key.
4. Run the application using a local web server.

## Features

- Search for weather by city name.
- Search using your current location.
- Display temperature, wind speed and weather icons.
- Save the five most recent searches using localStorage.
- Display error messages using Bootstrap Popover.
